# Mac Faldet

Before that, ten years across banking, commodity markets, software and government.

[Docs](https://mfaldet.github.io/localvision/docs/) · [Live demo](https://mfaldet.github.io/localvision/) · [Write-up](https://faldetadvisory.com/examples/good-dashboard)

[App Store](https://apps.apple.com/app/roll-along-marble-maze/id6774455345) · [Write-up](https://faldetadvisory.com/examples/roll-along)
- [Pour](https://github.com/mfaldet/pourart), a pour-painting app on a real fluid simulation.
